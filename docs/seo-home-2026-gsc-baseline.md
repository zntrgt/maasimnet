Bu belge kesin aylık arama hacmi değildir; yalnız mevcut GSC görünürlüğünü değişiklik öncesi baseline olarak kaydeder.

## Değişiklik gerekçesi

Final production build incelendiğinde ana sayfada 2026 sinyali zaten güçlüydü; `2026` metni yoğun biçimde mevcutken 2021–2025 ifadeleri ana sayfa içeriğinde bulunmuyordu. Bu nedenle eski yıl sorgularındaki gösterimler içerik temizleme problemi olarak ele alınmadı.

Optimizasyonun amacı keyword yoğunluğunu artırmak değil, primary query sahipliğini tutarlı hale getirmektir:

- Primary: `maaş hesaplama 2026`
- Secondary: `brütten nete maaş hesaplama 2026`, `netten brüte maaş hesaplama 2026`, `brüt net maaş hesaplama 2026`

Title, H1, hero ve WebApplication/WebPage schema aynı sahiplik etrafında hizalanır. Dedicated asgari ücret, vergi dilimi, tazminat ve diğer hesaplayıcı URL'lerinin primary intentleri korunur.

## Ölçüm

Değişiklik canlıya alındıktan sonra 28 günlük yeni dönem, bu baseline ile aşağıdaki metriklerde karşılaştırılmalıdır:

- impressions
- clicks
- CTR
- average position
- query bazında landing page
- `maaş hesaplama 2026` ve brüt/net varyasyonlarının pozisyon dağılımı
- ana sayfanın toplam organik görünürlük payı

Tek impression'lı sorgularda kısa dönem pozisyon değişimleri başarı/başarısızlık olarak yorumlanmamalıdır.
